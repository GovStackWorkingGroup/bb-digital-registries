# Consultation API reference

Use this API to read permitted Records through declared logical Collections without changing the authoritative source. A deployment independently selects Retrieve, exact Lookup, bounded List, typed Search, Revision List, or Revision Retrieve, and publishes the schemas, access rules, and selectable features for the operations it supports.

The [canonical Consultation OpenAPI](../api/openapi.yaml) is the normative transport entry point for this DRAFT specification, but the draft is not ratified and does not establish an approved conformance target. The [birth-registration](api-examples/birth-registration.md), [business](api-examples/business.md), and [household](api-examples/household.md) contracts show illustrative deployment bindings and do not add requirements to the canonical contract.
