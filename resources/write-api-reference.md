# Write API reference

The [canonical Write OpenAPI](../api/write.openapi.yaml) defines independently selected direct creation, update, named transition, and approval-based change-request operations. Its requirements remain DRAFT and do not establish an approved conformance target. The [Write binding](write-binding.md) defines proposal and source preconditions, review/application outcomes, and declared commit guarantees.

The [non-normative example contract](../api/examples/write-examples.openapi.yaml) and [example guide](api-examples/README.md) illustrate birth registration and household journeys. Their domain models remain institution-selected examples and are not part of the shared Write requirements.
