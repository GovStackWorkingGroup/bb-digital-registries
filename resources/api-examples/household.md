# Household Registry API example

Use this example to retrieve a permitted household Record with its embedded address and bounded membership details. Memberships can reference related Records in an Individuals Registry while retaining the household Record as the resource being read.

The [household Registry OpenAPI](../../api/examples/household-registry.openapi.yaml) is an illustrative deployment binding of the [canonical DRAFT Consultation contract](../api-reference.md), not a normative extension or a ratified household Registry profile. Its components, bounds, disclosure rules, and relationship meanings do not impose a universal household data model.
